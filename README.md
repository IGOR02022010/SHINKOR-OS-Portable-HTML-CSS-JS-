<h1>Для пользователей:</h1>
<hr>
Этот проект не связан с компанией LG и не является официальным продуктом компании и поэтому ЭТО НЕ ПРОДУКТ КОМПАНИИ LG <br><br>
Чтобы запустить SHINKOR OS, запустите файл RUNinHTM.htm (Через браузер(Лежит в корне архива)), или запустите RUN_OS.bat (На Windows)......<br><br>
1) Проект бесплатный и без лицензии. (Можете делать с ним что угодно)<br>
-- Для проверки целостности файлов, можете сравнить хэши (Файл с хэшами лежит в .[System_UI]/[SHA-256]/)<br><br>
2) Этот проект можно запускать на любом устройстве где есть браузер, и всё автономно (Не требует подключение к интернету)<br>
-- Например вы можете сделать из андроида пародию настольного ПК (Открываете RUNinHTM.htm, подключаете мышь и клавиатуру (Через OTG или Bluetooth) и нажимаете F11)<br><br>
SHINKOR OS Portable полностью русскоязычный (Но в некоторых местах есть английский)<br><br>
3) Есть встроенный HTTP сервер (В корне архива файл RUN_SwServer.py)
-- Если хотите чтобы SHINKOR OS Portable запускался при запуске ПК (Только Windows), тогда запустите файл .[System_UI]/AvRanADD.bat
---- А чтобы отменить автозапуск, тогда запустите файл .[System_UI]/AvRanDEL.bat<br><br>
4) Одна вкладка занимает примерно 51 мб ОЗУ (Для быстродействия и экономии ОЗУ всё будет работать в одной вкладке!!!)<br>
-- Чтобы создать новое плавающее окно, тогда на физической клавиатуре нажмите ` (Для этого включите английскую раскладку и нажмите на кнопку на которой написано: `~ё (В версиях после 23.08.2026 достаточно нажать комбинацию(Ctrl+q)))<br><br>
5) Дополнительная информация находится в .[System_UI]/.[APP;HELPmpiS].htm<br>
-- В SHINKOR OS Portable имеется более 34 программ, и всё полностью функционирует, и моя OS подходит для начинающий веб-разработчиков как пособие и объект модификаций и может работать вместо Windows (Для этого откройте AvRanADD.bat, а чтобы убрать автозапуск, тогда нажмите на AvRanDEL.bat).<br>
---- И я создавал SHINKOR OS Portable с учётом недостаток, например как у eyeOS, а именно такие OS нельзя просто открыть в браузере, из за того что они работают на фреймворках и часто на PHP, поэтому я устранил эту проблему чтобы можно было запускать в любом браузере с любого накопителя.<br>

Примечание: 
<hr>
 А ещё у проекта есть встроенный сервер воркер (sv.js), и можно сделать из этого сайт или локальный облачный ПК (С помощью HTTP сервера:  RUN_SwServer.py или .[System_UI]/.[Shinkor_link].py) <br><br>
---- Если вы распакуете проект в корневой каталог флешки, и вставите в ноутбук, то у флешки поменяется иконка и имя (Не переживайте, потому что реальное имя флешки не меняется)<br><br>
---- Есть в общем только три операционки:  Start UHON.htm (В виде операционки смартфона),  SEos.htm (Для кнопочных телефонов или старых браузеров) и основная Start SHINKOR.htm (Похожа на виндовс)<br><br>
---- Можно менять обои рабочего стола с помощью файла .SwitchBG.py (Находится в корневом каталоге архива, и создаёт графическое диалоговое окно)<br><br>
---- Структура сделана так, что если где будет ошибка, то вся ВебОС продолжит работать потому что имеет он написан сразу на CSS/JS/HTML (Модулями и несколькими файлами) вместо одного большого Java Scipt файла (Для экономии ОЗУ и для отказоустойчивости, чтобы система работала без задержек и более стабильно)<br><br>
---- SHINKOR OS Portable имеет современный интерфейс благодаря HTML5 и CSS3 продуманному дизайну.<br><br>
---- Это одна из самых приватных браузерных операционных систем, потому что SHINKOR OS Portable не отправляет данные в интернет и не кэширует данные даже при подключённом интернете<br><br>
---- Эта браузерная операционная система полностью адаптируется под размер экрана, и поэтому может работать на разных устройствах (Смартфон, планшет, ПК, ноутбук и др.) но пользователь может подогнать размер под себя (Ctrl+, Ctrl- или колесо мыши и Ctrl)
