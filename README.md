|   Чтобы запустить SHINKOR WebOS, запустите файл RUNinHTM.htm (Через браузер(Лежит в корне архива)), или запустите RUN_WebOS.bat (На Windows)......
|
|
| 1) Проект бесплатный и без лицензии..... (Можете делать с ним что угодно)
|---- Для проверки целосности файлов, можете сравнить хэши (Файл с хэшами лежит в .[System_UI]/[SHA-256]/)
|

|---- Например вы можете сделать из андроида породию настольного ПК (Открываете RUNinHTM.htm, подключаете мышь и клавиатуру (Через OTG или Bluetooth) и нажимаете F11)
|
| SHINKOR WebOS Portable полностью русскоязычный (Но в некоторых естах есть английский)
|
|
| 3) Есть встроеный HTTP сервер (В корне архива файл RUN_SwServer.py)
|---- Если хотите чтобы SHINKOR WebOS Portable запускался при запуске ПК (Только Windows), тогда запустите файл .[System_UI]/AvRanADD.bat
|-------- А чтобы отменить автозапуск, тогда запустите файл .[System_UI]/AvRanDEL.bat
|
|
| 4) Одна вкладка занимает примерно 51 мб ОЗУ (Для быстродействия и экономии ОЗУ всё будет работать в одной вкладке!!!)
|---- Чтобы создать новое плавающее окно, тогда на физической клавиатуре нажмите ` (Для этого включите английскую раскладку и нажмите на кнопку на каторой написано: `~ё)
|
| 5) Дополнительная информация находится в .[System_UI]/.[APP;HELPmpiS].htm
|---- В SHINKOR WebOS Portable имеется более 34 программ, и всё полностью функционирует, и моя WebOS подходит для начинающий веб-разработчиков как пособие и объект модификаций и может работать вместо Windows (Для этого откройте AvRanADD.bat, а чтобы убрать автозапуск, тогда нажмите на AvRanDEL.bat).
|-------- И я создавал SHINKOR WebOS Portable с учётом недостаток, например как у eyeOS, а именно такие WebOS нельзя просто открыть в браузере, из за того что они работают на фреймворках и часто на PHP, поэтому я устранил эту проблему чтобы можно было запускать в любом браузере с любого накопиеля.

Для разработчиков:
_________________________________________________________
 Для того чтобы добавить свою программу написанную на HTML\CSS\JS, тогда сделайте так:
---- Скопируйте файл .[System_UI]/[a=DEV=a]/.[pUSER;  ].htm
---- Вставите его в .[System_UI]/ и измените имя файла например на .[pUSER;test].htm
---- Затем вставите свой код в этот файл (Внутри есть специальное обозначение о том где именно его писать)
---- Затем найдите файл .{Menu_AIfolder}.htm и найдите место где прописаны кнопки приложений (Если что там есть специальное поле для этого среди кнопок) и вставите туда код:


<form class="hea4" action=".[pUSER;test].htm"><button style="color: white; display: flex; align-items: center; gap: 8px;" type="submit">
    <img src=".(RES)/APP.png" alt="Image" style="height: 20px; width: 20px;  "> Programm 447711
</button></form>
<hr>


Подробности: 
  
    action=".[pUSER;test].htm"  это то какой файл открывать
	
	img src=".(RES)/APP.png" это иконка приложения (Стоит по умолчанию но можно изменить с помощью .[pUSER;PRapp].htm)
	
	Programm 447711  это название приложения (Тоже можно изменить)

Примечание:
_________________________________________________________
 А ещё у проекта есть встроеный сервер воркер, и можно сделать из этого сайт или локальный облачный ПК (С помощью HTTP сервера:  RUN_SwServer.py или .[System_UI]/.[Shinkor_link].py) 
---- Если вы распакуете проект в корневой католог флешки, и вставите в ноутбук, то у флешки поменяется иконка и имя (Не переживайте, потому что реальное имя флешки не меняется)
---- Есть в общем только три операционки:  Start UHON.htm (В виде операционки смартфона),  SEos.htm (Для кнопочных телефонов или старых браузеров) и основная Start SHINKOR.htm (Похожа на видовс)
---- Можно менять обои рабочего стола с помощью файла .SwitchBG.py (Находится в корневом каталоге архива, и создаёт графическое диалоговое окно)
---- Структура сделана так, что если где будет ошибка, то вся ВебОС продолжит работать потому что имеет он написан сразу на CSS/JS/HTML вместо одного большого Java Scipt файла (Для экономии ОЗУ и для отказоустойчивости)
